Cuándo y cómo utilizarlo

  • showRich: muestra datos que el usuario debe reconocer.
  • confirmRich: devuelve un booleano antes de guardar o rechazar.
  • tone: acepta info, success, warning o danger.
  • details: organiza campos; wide ocupa la fila completa.
  • badge y note: destacan estado y consecuencia sin texto plano.
  • Los valores se renderizan como texto Angular; no construya HTML con datos del API.
